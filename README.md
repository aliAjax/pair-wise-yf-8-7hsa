# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、按洗印批号追踪同批风险、逐段复查、统计可放时长并导出核对清单。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。所有数据保存在浏览器 localStorage，关掉页面再打开继续。

## 批号与同批风险联动

- 每个片段登记洗印批号（录入或点卡片上的“改”编辑）。
- 同批任一段出现偏色或破损时，该批其余片段自动进入**待复查**：保留在放映顺序原位置，时长**不计入可放时长**，卡片以斜纹标识。
- 右侧“同批风险核对”按批号列出问题源与被关联的片段，以及各自复查进度；未登记批号的破损段单独提示补登。
- 顶部实时显示**待复查片段数**，并区分可放时长与总时长。

## 逐段复查

- 卡片上点“✓ 复查合格”：恢复计时（问题源合格同样恢复）。
- 点“✕ 复查不合格”：弹窗登记**处理人**与**处理说明**，该段不计时长。
- 合格/不合格都可以再次点击重新判定。
- 改批号、颜色偏移或破损情况后，受影响批号（含新旧两批）及该段的旧复查结论自动失效并重新判定；新增片段进入风险批号、删除问题源解除批号风险时同理。

## 其他

- 支持拖拽/按钮调整放映顺序、按颜色和复查状态筛选、按编号/批号/备注/处理人搜索；点卡片上的批号标签可快速只看同批。
- 导出为带 BOM 的 UTF-8 文本清单，包含序号、洗印批号、时长、颜色、破损、问题原因、复查处理结果（含处理人与说明）及备注。
